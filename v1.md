# Commands

```sh
# start slopbox + custom runtime options
slopbox run

slopbox run --config /path/to/config.json

slopbox run --profile python

slopbox run --runtime vm|container

# dump default config
slopbox init

# check if docker, docker compose and nix are OK
slopbox health

# dump final config
slopbox config

# build the current configuration but don't run anything (will be saved to .local/state/slopbox/<config-hash>)
slopbox build
```
